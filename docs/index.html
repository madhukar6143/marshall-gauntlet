01 TAINT

The moment the agent reads untrusted content, the gateway marks the session tainted — one bit most gateways don't track.

02 DENY

Reads of secret paths (**/.env, keys, certs) are hard-denied — credentials never reach the model.

03 HOLD

Once tainted, privileged actions — POST, file writes, shell — are held for approval. The exfil or wipe never completes.
